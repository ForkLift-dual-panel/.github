# ForkLift — File Manager With FTP, SFTP, Amazon S3 Support

## About ForkLift

ForkLift provides a dual-panel file manager for macOS with integrated support for FTP, SFTP, WebDAV, Amazon S3, Backblaze B2, Google Drive, Dropbox, OneDrive, Box, and other cloud services. ForkLift combines local file management (dual-panel navigation, batch rename, folder sync, file comparison) with remote connectivity (browse, upload, download, edit remote files). ForkLift enables users to transfer files between any connected location — drag from local to FTP, copy from S3 to Dropbox, sync folders across servers. ForkLift is trusted by web developers, system administrators, designers, and power users who need a single app for all file operations.

## Deep Dive — Dual-Panel File Manager With Remote Support

Dual-panel interface — left and right panels (local, remote, or cloud), drag-drop between panels, keyboard shortcuts (F5 copy, F6 move)  
Remote protocols — FTP, FTPS, SFTP, WebDAV, WebDAVS, AFP, SMB (Windows shares)  
Cloud services — Amazon S3, Backblaze B2, Google Drive, Dropbox, OneDrive, Box, MEGA  
File sync — synchronize folders (local ↔ local, local ↔ remote, remote ↔ remote), preview changes before sync, mirror or merge modes  
Batch rename — regex patterns, numbering, find/replace, case conversion, extension manipulation  
File comparison — compare two directories (highlight differences), compare text files (diff viewer)  
Synced browsing — browse remote and local folders in parallel, automatic path synchronization  
Remote editing — edit files on server directly (integrated editor or external app), auto-upload on save  
Queue manager — transfer queue, pause/resume, parallel transfers (up to 10 concurrent), bandwidth limiting
